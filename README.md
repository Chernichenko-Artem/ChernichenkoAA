# VK Currency Bot
Бот для конвертации валют.
Поддерживает:
- евро
- доллар
- рубль

/start или /help	Показать инструкцию
/values	Список доступных валют
<валюта1> <валюта2> <количество>	Конвертировать валюту

Пример использования:
евро доллар 100

Запуск:
pip install -r requirements.txt
создать config.py с токеном
python main.py
